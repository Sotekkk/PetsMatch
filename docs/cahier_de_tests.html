Cahier de tests — appli

Ce cahier suit PetsMatch profil par profil, de la création du profil jusqu'à chaque fonctionnalité. Pour chaque ligne : faites l'action, vérifiez le résultat attendu, cochez si c'est bon. Si quelque chose ne va pas, laissez la case vide et écrivez ce que vous avez vu dans la ligne de remarque.

Avant de commencer

  • Installez l'appli : le fichier APK (Android) ou le lien TestFlight (iPhone) envoyé par Angélique.
  • Ouvrez petsmatchapp.com. Le site demande un mot de passe d'accès bêta : Angélique vous le donne.
  • Utilisez votre propre adresse e-mail : vous recevrez de vrais e-mails (confirmation, contrats, factures).
  • Ne payez rien pour de vrai. Pour tester une formule payante (Essentiel, Premium), demandez à Angélique de l'activer.

Un compte, plusieurs profils

Vous créez un seul compte. Vous commencez par le profil Particulier, puis vous ajoutez chaque profil pro (élevage, pension, toiletteur…) depuis le menu. On passe de l'un à l'autre sans se déconnecter. Un profil pro doit parfois être validé : prévenez Angélique quand vous en créez un.

Les tests à deux

Les lignes À deux se font avec Angélique : l'une joue le client (Particulier), l'autre le professionnel. Faites chaque scénario dans les deux sens quand c'est possible.

À deux avec Angélique Appli seulement sur l'appli Site seulement sur le site

Pour imprimer, choisissez la version puis utilisez l'impression de votre navigateur (Ctrl + P) : chaque profil commence sur une nouvelle page, avec ses lignes de remarque.

Signaler un problème

Pour chaque problème, notez ces cinq informations : elles permettent de le corriger vite.

Où

Le profil actif et l'écran (par exemple « Pension, Nos pensionnaires, menu Actions »).

Ce que vous avez fait

Les étapes dans l'ordre, jusqu'au problème.

Ce qui s'est passé

Le message affiché, l'écran blanc, la donnée fausse ou manquante.

Ce que vous attendiez

Le résultat attendu écrit dans ce cahier, ou ce qui vous semblait logique.

Une capture d'écran

Avec l'heure, et le modèle du téléphone ou le navigateur utilisé.
